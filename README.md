# OpenCV 智能视觉监控与入侵报警系统

Intelligent Video Surveillance and Intrusion Detection System Based on OpenCV

## 一、项目简介

本项目基于 Python、OpenCV 和 PySide6 开发，是一套集实时视频监控、运动目标检测、区域入侵报警、事件录像及报警数据可视化于一体的桌面监控系统。

系统支持电脑摄像头、USB 摄像头及安卓手机 Wi-Fi 摄像头接入，通过计算机视觉算法检测监控区域内的运动目标，并在发生入侵事件时自动保存截图、录像及报警记录。

项目面向智能安防与物联网视频监控应用场景，重点实现视频采集、实时图像处理、事件检测和数据管理等功能。

## 二、技术栈

| 技术 | 主要用途 |
|---|---|
| Python | 核心业务逻辑 |
| OpenCV | 视频采集、图像处理与运动检测 |
| PySide6 | 桌面图形用户界面 |
| SQLite | 报警记录存储与管理 |
| NumPy | 图像数组处理 |
| Pillow | 视频画面中文文字绘制 |
| QThread / threading | 视频采集及录像任务处理 |
| deque | 报警前历史视频帧缓存 |

## 三、核心功能

### 1. 多摄像头视频监控

- 支持电脑内置摄像头及 USB 摄像头
- 支持安卓手机 Wi-Fi 网络视频流接入
- 支持摄像头扫描、切换和自定义命名
- 支持摄像头断线检测与手动重新连接

### 2. 智能运动检测与区域入侵报警

- 基于 MOG2 背景减除算法检测运动目标
- 结合图像形态学处理和轮廓分析识别运动区域
- 支持通过鼠标绘制自定义监控区域
- 支持调整运动检测灵敏度
- 通过连续多帧确认机制减少瞬时干扰
- 检测到区域入侵时自动触发报警

### 3. 自动截图与事件录像

- 入侵事件发生时自动保存报警截图
- 自动生成 MP4 格式的事件录像
- 使用 deque 环形缓冲区缓存历史视频帧
- 支持保留报警前约 5 秒及报警后约 10 秒的视频
- 将录像文件与对应报警记录关联，方便后续查看

### 4. 报警记录管理

- 使用 SQLite 数据库存储报警事件
- 支持查看报警时间、类型、截图及录像
- 支持报警记录关键词、处理状态和日期筛选
- 支持将报警记录标记为已处理
- 支持 CSV 数据导出，可使用 Excel 或 WPS 查看

### 5. 数据可视化

- 展示累计报警、今日报警、已处理及未处理报警数量
- 展示最近 7 天报警趋势
- 展示不同时间段的报警分布
- 展示摄像头连接状态与系统运行状态

## 五、运行环境

- Windows 操作系统
- Python 3
- 摄像头或可访问的网络视频流

安装主要依赖：

```bash
pip install opencv-python numpy PySide6 Pillow
```

运行主程序：

```bash
python app.py
```

首次运行时，请根据实际设备情况选择摄像头并配置视频流地址。

## 六、核心实现思路

### 运动目标检测

通过 OpenCV 的 MOG2 背景减除算法提取前景运动区域，对前景掩码进行阈值处理、形态学运算和轮廓提取，再结合面积阈值与自定义监控区域判断是否存在入侵行为。

### 事件录像回溯

系统持续缓存最近一段时间的视频帧。当检测到区域入侵时，读取缓冲区中的历史帧，并结合报警发生后的新视频帧生成 MP4 录像，从而保留事件发生前后的监控画面。

### 多线程处理

使用 QThread 处理摄像头采集与实时检测，通过 Qt 信号将视频帧及状态更新传递到界面；使用独立线程执行事件录像写入，减少录像编码对实时监控的影响。
